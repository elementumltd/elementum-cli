# Objects

Commands for listing and managing Elementum objects (apps, elements, and tasks).

## Available Commands

| Command | Purpose |
|--|--|
| list | List all objects (apps, elements, and tasks) |
| search | Search for objects (apps, elements, tasks) |
| show | Show detailed information about an object |
